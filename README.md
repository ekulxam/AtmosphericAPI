# THIS IS A LIBRARY MOD. THIS DOES NOT DO ANYTHING ON ITS OWN.

## Atmospheric API
SkyNotTheLimit's `moddernamelib`. Adds miscellaneous utilities for use in mods.

Usage examples include:
- Post-effect shader application
- Overlay rendering
- Custom spyglasses
- Damage type tags to bypass creative and spectator invulnerability
- Datapack datagen
- Easy resource loading
- Directional particles
- Lists of resource packs as configs
- Two-handed items
- Non-living entities with attributes
- Block registry shenanigans
- `Codec` and `PacketCodec`/`StreamCodec` helpers
- Multiversion helpers
- Scrolling text gradients
- More splashes
- Screenshake
- (Basically) useless annotations

To use, pull the desired version from the Modrinth maven, or alternatively, download it from source and publish it to your mavenLocal.
